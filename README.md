# Bipul 3D Portfolio

This version is intentionally a **single `index.html` file**. It has no external CSS/JS/image paths, so the portfolio itself cannot break because an `amazon/` or other folder is missing.

## GitHub upload
Upload `index.html` to the **root of your `portfolio` repository**. Commit it. Then GitHub:
Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

Expected URL:
https://bipulbabu.github.io/portfolio/

Projects included:
- NexaCart
- CalcSphere

The project cards use internal anchors, not missing folders. When a real live-demo URL is ready, it can be added later.
