# Bipul Advanced 3D Portfolio

Single-file futuristic portfolio for GitHub Pages.

## Files
- `index.html` — complete portfolio, CSS, 3D effects, animations and JavaScript in one file.

## Deploy
Upload `index.html` to the root of the `bipulbabu/portfolio` repository.
GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Live URL:
https://bipulbabu.github.io/portfolio/
